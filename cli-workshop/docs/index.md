Praktyczny warsztat GitHub Copilot CLI przygotowany na **GitHub Dev Days Gdańsk** (28.10.2026, Capgemini, Olivia Six).

Pracujesz w terminalu na realnej aplikacji **Tailspin Toys** i wspólnym backlogu zadań: planujesz zmiany, generujesz kod, weryfikujesz zachowanie, recenzujesz pull requesty i zarządzasz pracą agentów.

## Zacznij tutaj

- [Wprowadzenie do warsztatu](/gdn-dev-days-2026/cli-workshop/real-world-development/cli/) — co zbudujesz i jak wygląda przebieg
- [Wymagania wstępne](/gdn-dev-days-2026/cli-workshop/real-world-development/cli/0-prerequisites/) — własna kopia projektu i codespace

## Czas i poziom

Około **2 godziny**, poziom średnio zaawansowany. Potrzebujesz konta GitHub z dostępem do Copilota oraz przeglądarki — resztę załatwia GitHub Codespaces.
